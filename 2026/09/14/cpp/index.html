一、源码怎么变成能跑的程序

.cpp 不能直接运行，要先编译，再连接，最后得到 .exe。

各是什么

名字 一句话
源代码 你写的 .cpp，给人看的
编译器 把源码翻译成机器码（还是半成品）
目标代码 编译出来的 .obj / .o，零件，还不能单独跑
连接程序 把零件拼成完整程序
启动代码 程序启动时先跑它，再进你的 main()
库代码 现成功能，比如 cout，不用自己写
可执行代码 最终的 .exe，双击就能跑

记住两点

  1. 编译：源码 → 目标文件（翻译）
  2. 连接：目标文件 + 启动代码 + 库 → .exe（组装）

IDE 里点运行，背后就是这两步。

二、头文件和命名空间

1. 头文件（就是个真文件）

头文件是磁盘上的真实文件。#include 会把它的内容粘贴进你的 .cpp。

说它像“说明书”，只是比喻它的作用：多半先告诉编译器有哪些名字可用；真正实现常常在别处（连接时再链上）。

  • iostream：标准库的一部分，负责输入输出的那个头文件
  • 没有 #include <iostream>，编译器就不认识 cout
  • 标准库头文件一般不写 .h（和旧 C 的 stdio.h 区分，名字放进 std）；自己写的仍可用 xxx.h

一句话：想用谁，就 include 谁。

2. 标准库、#include、std 别搞混

词 是什么
标准库 C++ 自带的整套工具（iostream、string 等都是它的一部分）
#include 把某个头文件贴进来 → 决定「有没有」这个名字
std 命名空间（姓/分组），不是文件，不能 #include <std> → 决定「是谁家的」

常见误会：以为 std 像 include，引入 std 才有 cout。
不对。要两步：

  1. #include <iostream> → 才有 cout 可用
  2. std::cout → 指明用的是标准库那份
写法 说明
std::cout 稳妥，入门先用这个
using namespace std; 省事，小练习可以

一句话：#include 管有没有，std:: 管是谁家的。

3. 最小例子

  • #include <iostream>：贴入标准库的输入输出头文件
  • std::cout：标准输出
  • main()：入口，返回 0 表示正常结束

三、声明、赋值与类型大小

1. 字节和比特

单位 关系
比特 bit 最小单位，只能是 0 或 1
字节 byte 1 字节 = 8 比特

说类型“占多大”，通常说字节（sizeof 返回的也是字节数）。

2. 声明和赋值（跟内存的关系）

  • 声明：占坑（分配空间 + 起名）
  • 赋值：往坑里放值
  • 只声明不赋值，局部变量里往往是垃圾值（内容未定义）

3. 基本类型大概占多少（常见 PC）

以字节计。具体以你机器为准：sizeof(类型)。

类型 常见大小 有无符号
bool 1 字节 —
char / signed char 1 字节 有符号（char 是否带符号看编译器）
unsigned char 1 字节 无符号
short / short int 2 字节 有符号
unsigned short 2 字节 无符号
int 4 字节 有符号
unsigned int 4 字节 无符号
long 4 或 8 字节 有符号（Windows 常 4，Linux 64 位常 8）
unsigned long 同 long 无符号
long long 8 字节 有符号
unsigned long long 8 字节 无符号
float 4 字节 浮点（本身不分 signed/unsigned）
double 8 字节 浮点
long double 8 / 10 / 16 等 浮点，看平台

4. 有符号 vs 无符号（整数）

同一大小，差别在怎么解释比特：

有符号 signed 无符号 unsigned
能不能表示负数 能 不能（≥ 0）
例子（1 字节） 大约 -128 ~ 127 0 ~ 255
例子（4 字节 int） 约 ±21 亿 0 ~ 约 42 亿
  • 有符号 / 无符号：字节数通常一样，只是取值范围不同
  • 默认 int、short 等是有符号；要无符号就写 unsigned

5. 越界（超出类型能表示的范围）

类型有上下限。塞进去的值超出范围，结果未定义或绕回，别指望“自动变对”。

一句话：别让数超出该类型能装的范围。

6. <climits>：查整型上下限

常见宏：INT_MAX / INT_MIN、SHRT_MAX、LONG_MAX、LLONG_MAX、UINT_MAX 等。

7. 整型字面量 & cout 进制

字面量（代码里直接写的数）默认是十进制：

写法 进制 例子
普通数字 十进制 42
0 开头 八进制 052（= 十进制 42）
0x / 0X 十六进制 0x2A（= 42）
0b / 0B（C++14） 二进制 0b101010（= 42）

cout 默认也按十进制打印。要换进制输出：

一句话：声明占空间，赋值填内容；大小看字节；越界别碰；上下限看 climits；字面量和 cout 默认都是十进制。

四、char、ASCII、cout.put

1. char 是什么

  • 一般占 1 字节，用来存一个字符
  • 内存里存的其实是整数编号（ASCII 码），不是字形本身
  • 例：'A' 对应 65，'a' 对应 97，'0' 对应 48

字符字面量用单引号 'A'；字符串用双引号 "A"（那是字符串，不是单个 char）。

2. cin / cout 和 ASCII

操作 发生什么
cin >> ch（ch 是 char） 读入字符 → 转成对应 ASCII 编号存进 ch
cout << ch 把编号按字符显示出来（65 → 屏幕上的 A）
cout << int(ch) 强制当整数打，看到的是编号 65

一句话：变量里是编号，cout 默认按字符显示；想看编号就转成 int。

3. cout.put() 以及类 / 对象 / 成员函数

put：专门输出一个字符的函数。

关系可以这样记：

名字 角色 白话
ostream 类（类型/图纸） 规定“输出流长什么样、能干什么”
cout 对象（按图纸造出来的实例） 标准输出这个具体东西
put 成员函数（对象身上的功能） 属于这类对象的一个操作

所以 cout.put('A') = 对象 cout 调用它的成员函数 put。
cout << 'A' 更常用；put 入门了解即可。

4. 转义字符

有些字符没法直接写进代码里，比如：

  • 换行：你敲回车，源码就换行了，字符串就断了
  • 引号 "：和字符串的引号冲突
  • 反斜杠 \ 本身也有特殊含义

所以用 \ + 字母 表示这些特殊字符，叫转义字符。

转义 含义
\n 换行
\t 制表符（Tab）
\\ 反斜杠本身
\' 单引号
\" 双引号
\0 空字符（字符串结尾用）

一句话：键盘不好直接写进代码的字符，用 \ 转义来表示。

5. 宽字符与国际化（了解即可）

普通 char 一个字节，装不下世界上所有文字。

类型 一句话
wchar_t 宽字符，字面量用 L'中'、L"你好"
char16_t / char32_t 固定 16/32 位字符（C++11）
wcout / wcin 宽字符版输入输出

入门先用好 char 和普通字符串就行；做多语言界面时再深入 Unicode / UTF-8。

6. bool（布尔类型）

只有两个值：true（真）、false（假）。常见占 1 字节。

  • bool 和整数可隐式转换：true↔1，false↔0；整数 0 为假，非 0 为真
  • cout 默认打 1/0(这是 C++ 一开始就定好的默认习惯)：没开 boolalpha 时，它按整数形式输出（走的就是上面这套 0/1 转换）

五、const 与 #define

两者都能表示“不变的量”，但机制不同。

#define const
是什么 预处理宏，文本替换 有类型的常量
何时处理 编译前，直接换成字面量 编译时有类型检查
有没有类型 没有 有
入门建议 少用来当常量 优先用
  • #define 简单粗暴，但不安全（无类型、难调试、括号坑多）
  • const 更符合 C++：有类型、可作用域、更安全

一句话：表示常量，优先 const，少用 #define。

六、浮点数

1. 在内存里怎么存（IEEE 754）

小数不是按「整数那种直接存」，而是拆成三部分（类似科学计数法）：

部分 作用
符号位 1 比特：0 正，1 负（管整个数的正负）
指数位 表示数量级（2 的几次方，可正可负）
尾数位（有效数字） 表示具体精度

常见布局：

类型 总大小 符号 指数 尾数
float 4 字节（32 位） 1 8 23
double 8 字节（64 位） 1 11 52

指数、尾数“有正负”时怎么塞进比特

先把十进制数改成二进制的科学计数形式，例如：

① 符号位
只看最终结果是正是负 → 存 0 或 1。

② 指数位（指数可正可负，但不直接存负数）
指数位里存的是无符号整数，用**偏置（bias）**编码：

类型 偏置
float 127
double 1023

例（float，真实指数 = 2）：存 2 + 127 = 129 → 再写成 8 位二进制放进指数位。
真实指数 = -3 时：存 -3 + 127 = 124 → 仍然是正的比特串。
所以：指数可以是负的，但内存里看到的指数字段始终像“正整数”。

③ 尾数位（有效数字）
规格化后一般是 1.xxxx，那个前导 1 不存（隐藏位），只把小数点后的 xxxx 填进尾数字段；不够的后面补 0。
数的正负由符号位管，尾数字段本身按绝对值的小数部分来存。

一句话：符号位管正负；指数可正可负，但用“加偏置”存成无符号比特；尾数存 1. 后面的小数比特。

2. float 和 double 精度比较

float double
大小 4 字节 8 字节
有效数字（大约） 6～7 位十进制 15～16 位十进制
入门建议 少用 默认用这个

注意：

  • 浮点数本身常常是近似值：如 0.1 换成二进制是无限循环，位数有限，只能存“很接近”的值
  • 浮点加减也是近似的：两个近似值再运算，误差可能再被放大，所以 0.1 + 0.2 往往不等于精确的 0.3
  • 比较时别写 ==，看差值是否够小，例如 fabs(a - b) < 1e-9
  • 字面量默认是 double；要 float 就加 f（如 3.14f）

一句话：存的是近似，算的也是近似；别用 == 比浮点。

七、类型转换

不同类型互相赋值/运算时，编译器可能自动换类型，叫类型转换。

1. 常见两种

种类 说明 例子
隐式转换 编译器自动转 int n = 3.9; → n 变成 3（截断）
显式转换 你自己写明 int n = static_cast<int>(3.9);

2. 潜在问题

  • 丢精度：double → float，小数变粗
  • 截断：3.9 → int 变成 3，不是四舍五入
  • 溢出：大 int 塞进 short，可能乱套
  • 有符号/无符号混用：负数转 unsigned 会变成很大的正数

一句话：能转，但不一定安全；转的时候要想会不会丢信息。

3. 列表初始化不允许“缩窄”（C++11）

用 {} 初始化时，不允许偷偷丢掉信息（缩窄）：

一句话：{} 更严，防止你无意把小数塞进整数。

八、auto 与算术运算符

1. auto 声明（C++11）

让编译器根据右边的值自动推断类型：

  • 必须初始化（右边没有值就推不出来）
  • 少写类型名，但别滥用到看不懂代码

2. 算术运算符（入门）

运算符 含义
+ - * / 加、减、乘、除
% 取余（整数）
++ -- 自增、自减

注意：

  • 两个 int 相除 → 结果还是整数（7/2 得 3）
  • 想要小数，至少一侧是浮点：7.0/2 或 7/(double)2
  • % 一般只用于整数

一句话：auto 省得手写类型；整数除法会丢小数，要小数就用浮点。

九、复合类型

前面的 int、double 等是基本类型。
复合类型：把基本类型组合起来用，常见有数组、字符串、指针、结构体、引用等。

1. 数组

数组 = 同一类型的一串变量，在内存里挨着排。

  • 下标从 0 开始
  • 长度写在 [] 里，编译期一般要是常量（C++ 定长数组）
  • 访问越界不保证报错，但结果是错的/危险的

初始化规则和方法

注意：

  • 只声明不初始化：局部数组里往往是垃圾值
  • int a[5] = {1,2,3,4,5,6}; → 元素太多，错误
  • 数组不能整体直接赋值给另一个数组（要用循环或库来拷）

一句话：数组是一排同类型格子；{} 初始化时少写的补 0，多写的报错；下标从 0 起别越界。
