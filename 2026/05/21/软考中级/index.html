一、计算机系统

1. 计算机硬件组成

五大件：运算器、控制器、存储器、输入设备、输出设备

  • 运算器 + 控制器 = CPU
  • 存储器：存程序和数据（内存等）
  • 输入/输出设备：键盘、显示器等

2. CPU 的功能

  • 数据处理：算术运算、逻辑运算
  • 程序控制：按指令顺序执行，可跳转
  • 操作控制：发出控制信号，指挥各部件工作
  • 时间控制：用时钟节拍协调各部件时序

3. CPU 的组成

CPU = 运算器 + 控制器（现代 CPU 还含 Cache 等）

3.1 运算器

负责算术/逻辑运算，主要组成：

部件 作用
ALU（算术逻辑单元） 真正做加减乘除、与或非等运算
累加器（AC） 通用寄存器，暂存运算结果或中间数据
状态寄存器（PSW） 记运算状态：进位、零、溢出、符号等标志
数据缓冲寄存器（DR） CPU 与内存/外设交换数据时的临时缓冲

3.2 控制器

负责取指(指令=操作码+地址码)、译码、发控制信号，主要组成：

部件 作用
程序计数器（PC） 存下一条要执行指令的地址，自动 +1 或跳转改写
指令寄存器（IR） 暂存当前正在执行的指令
地址寄存器（AR） 保存当前cpu访问的内存单元地址
指令译码器（ID） 分析指令，解释指令操作码，弄清要干什么

4. 计算机基本单位

单位 含义
bit（位） 最小单位，0 或 1，最小的数据单位
Byte（字节） 1B（Byte） = 8b（bit），最小的存储单位
字（Word） 一次处理的二进制位数，与机器字长有关
KB / MB / GB / TB 1KB=1024B，1MB=1024KB，以此类推（2 的幂）

常用换算记：8bit = 1B，存容量按 1024 进位。

5. 进制转换

5.1 进制表示字母

字母 进制 例
B 二进制 Binary 1011B
O / Q 八进制 Octal 17O
D 十进制 Decimal 25D（可省略）
H 十六进制 Hex 1AH

十六进制数字：0–9，A–F（表示 10–15）。

5.2 n 进制 → 十进制：按权展开求和

每一位 ×（基数）^位数，再相加。

例：1011B → 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 8+0+2+1 = 11D

例：1A.8H → 1×16¹ + 10×16⁰ + 8×16⁻¹ = 16+10+0.5 = 26.5D

5.3 十进制 → n 进制：除 n 取余法

  • 整数部分：不断除以 n，取余数，余数倒着写（最后得到的余数是最高位）；直到商为 0 为止
  • 小数部分：不断乘以 n，取整数，正着写（先得到的是最高位）；直到小数部分为 0，或达到题目要求的位数为止

例：13D → 二进制
13÷2=6 余 1 → 6÷2=3 余 0 → 3÷2=1 余 1 → 1÷2=0 余 1
倒写：1101B

6. 原码、反码、补码、移码

以 机器数（符号位 + 数值位）表示有符号整数，符号位：0 正，1 负。

码制 正数 负数 特点
原码 符号位 0 + 真值 符号位 1 + 真值绝对值 直观；加减麻烦；+0、-0 两种零
反码 同原码 符号位 1，数值位按位取反 过渡码；也有 +0、-0
补码 同原码 反码 + 1（或模运算） 实际运算用补码；零唯一；减法变加法
移码 补码符号位取反 补码符号位取反 常作浮点阶码；便于比较大小

记口诀：正数三码相同；负数反码=原码数值位取反，补码=反码+1。

例（8 位）：-5
原码 10000101 → 反码 11111010 → 补码 11111011 → 移码 01111011

6.1 定点整数取值范围（共 n 位，1 位符号 + n-1 位数值）

码制 取值范围 为什么
原码 -(2^{n-1}-1) ~ +(2^{n-1}-1) 数值位全 1 最大为 2^{n-1}-1；有 +0、-0，占两个编码，表示不了 -2^{n-1}
反码 -(2^{n-1}-1) ~ +(2^{n-1}-1) 同原码，也有两个零
补码 -2^{n-1} ~ +(2^{n-1}-1) 把“负零”那个编码留给 -2^{n-1}，负数多一个，零唯一
移码 -2^{n-1} ~ +(2^{n-1}-1) 由补码符号位取反得到，能表示的数与补码一一对应，范围相同

例：n=8 → 原/反 [-127, 127]，补/移 [-128, 127]

6.2 定点小数取值范围（共 n 位，形如 ±0.xxx，1 位符号 + n-1 位小数）

码制 取值范围 为什么
原码 -(1-2^{-(n-1)}) ~ +(1-2^{-(n-1)}) 小数位全 1 最大为 0.111…1 = 1-2^{-(n-1)}；有 ±0，到不了 ±1
反码 -(1-2^{-(n-1)}) ~ +(1-2^{-(n-1)}) 同原码，也有两个零
补码 -1 ~ +(1-2^{-(n-1)}) “负零”编码留给 -1（补码 1.000…0），正数仍到不了 +1
移码 -1 ~ +(1-2^{-(n-1)}) 与补码对应，范围相同

例：n=8 → 原/反约 [-0.992, 0.992]，补/移 [-1, 约0.992]

对比记：原/反对称、有双零；补/移负数多一档（整数多 -2^{n-1}，小数多 -1）。

7. 浮点数

浮点数 ≈ 科学计数法：N = 尾数 × 基数^阶码

  • 阶码：决定小数点位置（表示范围），常用移码
  • 尾数：决定精度，常用补码，一般规格化（最高有效位为 1）
  • 基数：机器固定，多为 2

范围看阶码位数，精度看尾数位数。

7.1 规格化浮点数

规格化：让尾数的绝对值尽量大（用足精度），且表示唯一。基数为 2 时，要求尾数最高有效位为 1。

尾数形式 规格化样子（常见考点）
原码尾数 正数 0.1xxx…，负数 1.1xxx…（小数点后第一位为 1）
补码尾数 正数 0.1xxx…，负数 1.0xxx…（符号位与最高数值位相反）

怎么规格化：

  • 尾数左移 1 位 → 阶码减 1（反复直到满足上表）
  • 尾数右移 1 位 → 阶码加 1（溢出或运算后调整时用）

目的：提高精度、同一真值只有一种规格化表示。

8. 寻址方式

指令中给出操作数地址的方式（考点常考含义）：

方式 含义
立即寻址 操作数就在指令里，直接用
直接寻址 指令里给的是内存地址，去该地址取数
间接寻址 指令里给的是地址的地址（先取地址，再取数）
寄存器寻址 操作数在寄存器中
寄存器间接寻址 寄存器里存的是内存地址，再去内存取数
相对寻址 有效地址 = PC + 偏移量（常用于跳转）
基址/变址寻址 基址/变址寄存器 + 偏移量 → 有效地址

口诀：立即=数在指令；直接=指令给地址；间接=多找一层；相对=跟 PC 走。

9. 校验码

作用：发现或纠正数据传输出错。

9.1 奇偶校验码

  • 在数据旁加 1 位校验位，使 1 的个数为奇数（奇校验）或偶数（偶校验）
  • 只能检 1 位错，不能纠错，也检不出偶数位错
  • 简单、开销小

9.2 海明码（Hamming）

  • 插入多个校验位，能检错 + 纠正 1 位错
  • 校验位放在 2^k 位置（1、2、4、8…）
  • 软考常考：数据位 k、校验位 r 满足 2^r ≥ k + r + 1

9.3 循环冗余校验码（CRC）

  • 用双方约定的生成多项式做模 2 除，得到余数作校验码
  • 发送：数据 + CRC 校验位；接收：再除一次，余 0 则认为正确
  • 检错能力强，广泛用于网络、存储；一般只检不纠（或需重传）

对比记：

校验 检错 纠错
奇偶 弱（1 位） 否
海明 能 能纠 1 位
CRC 强 通常不纠
