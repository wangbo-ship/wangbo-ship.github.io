路线A：AI应用 + Agent开发（校招导向，2026企业招聘栈，LangChain+LangGraph）

目标岗位：大模型应用开发、AI应用工程师、Agent开发工程师
周期：7‑8个月可产出简历可投递项目；10‑12个月达到校招面试水平
招聘核心考察：Python工程、FastAPI后端、RAG全链路、LangChain组件、LangGraph状态Agent、Function‑Calling、向量库、异常处理、部署，不要求大模型训练微调

阶段1｜工程与LLM基础（4周）

  1. Python进阶：async异步编程、Pydantic数据校验、异常捕获、日志封装；能独立写工具类，不全靠AI生成完整代码
  2. 工程工具：Git、Docker基础、Linux常用命令，会看服务日志；基础数据库MySQL、Redis缓存原理与简单使用
  3. LLM基础概念：token、上下文窗口、temperature、流式输出、成本控制；各大模型SDK调用（DeepSeek、通义千问）
  4. Prompt工程：Zero‑shot、Few‑shot、CoT、强制JSON结构化输出（Agent工具调用必备）
  5. 学习LangChain基础组件：ChatModel、PromptTemplate、Parser、Document，理解LCEL链式编排

✅ 小Demo：脚本实现简历文本结构化抽取；封装可复用大模型调用SDK

阶段2｜RAG检索增强生成（AI应用核心，6周，JD高频考点）

  1. 文档处理：PDF/Markdown解析、文本清洗、分块策略（固定大小、语义分块），理解分块大小对召回效果的影响
  2. Embedding嵌入模型原理；向量数据库：FAISS → Chroma → Milvus（优先Milvus，企业主流）
  3. RAG完整链路实现：文档入库 → 向量化存储 → 检索召回 → Rerank重排 → LLM生成回答
  4. RAG调优：解决幻觉、召回差、噪声干扰；评估RAG效果指标
  5. 后端封装：FastAPI，把RAG封装成HTTP接口；处理并发、超时、参数校验

✅ 产出项目：私有知识库问答系统（标准AI应用简历项目）

阶段3｜Function Calling + Agent前置能力（3周）

  1. LLM工具调用原理，LangChain Tool封装、自定义工具开发
  2. 处理工具调用异常：参数错误、JSON解析失败、调用超时、失败重试
  3. 多轮对话、会话状态管理、上下文窗口裁剪；Redis存储会话

    区分：LangChain适合简单线性链路；复杂循环、分支任务需要LangGraph

✅ Demo：Agent自主判断，按需调用简历打分工具、岗位查询工具，不是手动触发

阶段4｜Agent开发（6周，重点LangGraph，校招加分核心）

  1. Agent理论：ReAct范式、Agent四大组件：规划、工具、短期记忆、长期记忆；了解MCP协议概念
  2. LangChain 高层Agent快速上手：预构建Agent、工具链；适合简单任务
  3. LangGraph重点攻坚（企业现在更看重）
    • StateGraph状态图、Node节点、Edge边、条件分支、循环
    • Checkpointer状态持久化、中断恢复、Human‑in‑the‑loop人工介入
    • 记忆实现：短期对话状态 + 向量长期记忆
  4. 任务拆解、多工具编排；处理Agent死循环、幻觉、任务失败兜底
  5. AutoGen/CrewAI简单了解，不做深挖；重点吃透LangGraph
  6. Agent评测方案：任务成功率、幻觉率，写简单评测脚本

✅ 产出完整项目：求职Agent系统（比赛+简历项目）

业务流程：上传简历 → Agent解析简历 → 岗位检索工具调用 → 岗位匹配打分 → 简历缺陷诊断 → 输出简历优化建议；包含异常重试、状态持久化。

阶段5｜工程化打磨 & 面试准备（2个月，贯穿后期）

  1. 系统增强：限流、缓存、日志、错误兜底、接口超时降级
  2. Docker打包部署，简单云服务器部署上线
  3. 项目深挖：能口述难点、踩坑、优化思路；面试官会问：不用LangGraph如何手写简易Agent状态机
  4. 面试题库：RAG全套面试题、LangChain/LangGraph区别、Agent死循环怎么解决、幻觉解决方案

完成后可以投递：AI应用工程师、大模型应用开发、Agent开发岗

路线B：CUDA AI‑GPU性能优化（AI‑Infra/GPU算子方向，校招向）

目标岗位：GPU算子工程师、推理引擎工程师、AI系统工程师、分布式训练工程师
周期：入门可写简历Demo需要8‑12个月；高质量项目12‑18个月
招聘核心考察：C++、计算机体系结构、GPU存储层级、CUDA Kernel手写、性能Profiler调优、计算/带宽瓶颈分析；了解LLM推理（KV‑Cache、Attention）

阶段0｜底层前置基础（8周，重中之重，0基础必须啃完再碰CUDA）

  1. C++进阶：C++11/17，指针内存管理、STL、模板、错误处理；能独立写中等规模C++代码
  2. 计算机体系结构：CPU缓存层级、带宽、算力、SIMD；理解计算bound/内存bound
  3. 操作系统基础：内存、线程、同步、竞争条件
  4. 并行计算基础：并行思维、归约、同步原语

阶段1｜CUDA基础编程（6周）

  1. CUDA编程模型：Grid‑Block‑Thread层级，Kernel核函数
  2. GPU存储层次：全局内存、共享内存、寄存器、常量内存；合并访问、warp、bank冲突
  3. 内存拷贝、同步__syncthreads()、原子操作；错误检查
  4. Nsight Profiler性能分析工具，定位性能瓶颈
    ✅ Demo：手写向量加法、向量归约求和Kernel，做性能对比

阶段2｜深度学习核心算子CUDA实现（8周，面试高频）

  1. GEMM矩阵乘法：理解tiling分块、共享内存优化GEMM；对比cuBLAS性能
  2. 基础深度学习算子：Softmax、LayerNorm
  3. Tensor‑Core、FP16/BF16混合精度原理；精度与性能权衡
    ✅ Demo：优化版GEMM CUDA Kernel，输出带宽/算力利用率

阶段3｜面向大模型LLM推理加速（8周，简历核心项目）

  1. Transformer GPU计算流程，KV‑Cache原理（面试必问）
  2. PagedAttention、vLLM核心原理阅读源码
  3. 实现简化版Attention CUDA算子 / 简化KV‑Cache算子；做性能调优
  4. 模型量化INT8/INT4原理了解

✅ 简历项目：简化版KV‑Cache/Attention CUDA算子，对比基准推理时延、显存占用

阶段4｜进阶拓展（有余力再学，非硬性）

  1. 分布式训练基础，NCCL通信基础概念
  2. 了解DeepSpeed/Megatron；昇腾CANN概念了解
  3. 推理框架：TensorRT基础概念

阶段5｜面试准备

  1. 手撕CUDA：归约、GEMM优化、合并访问、bank冲突
  2. LLM推理性能题：KV‑Cache显存计算，带宽算力瓶颈分析
  3. C++基础刷题，计算机底层原理复习

完成后可投递AI‑Infra、GPU算子、推理性能优化岗位；该方向岗位集中北上深。
