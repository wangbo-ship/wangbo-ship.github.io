Agent/大模型应用（武汉可改城市）：Boss 直聘搜「大模型应用」「Agent开发」「AI应用工程师」

主线1：AI 应用 → Agent → Harness（校招/硕毕导向）

背景匹配： 电子信息硕，工程底子可转应用开发；武汉可投本地 + 远程/大厂分站，主线先把可上线的 Agent 应用做扎实，再往 Harness（运行时底座） 加深，形成「会用 → 会造 Agent → 懂底座」的完整故事。

目标岗位： AI 应用工程师、大模型应用开发、Agent 开发工程师；进阶可看 Harness / Agent 基础设施（坑少，作加分与长期方向）

周期建议：

  • 7～8 个月：简历可投（RAG + 完整 Agent 项目）
  • 10～12 个月：校招/硕招面试较稳
  • 再 2～4 个月（可选）：Harness 向加深，冲击高阶工程表述

招聘核心考察： Python 工程、FastAPI、RAG 全链路、LangChain/LangGraph、Function-Calling、向量库、异常与部署；进阶考 Agent loop、工具/沙箱、状态与可观测性。主线不要求会训基座大模型。

阶段1｜工程与 LLM 基础（4周）

  1. Python 进阶：async、Pydantic、异常、日志；能独立写工具类，不全靠 AI 生成完整代码
  2. 工程工具：Git、Docker 基础、Linux；MySQL、Redis 简单使用
  3. LLM 概念：token、上下文窗口、temperature、流式输出、成本；DeepSeek / 通义等 SDK 调用
  4. Prompt：Zero-shot、Few-shot、CoT、强制 JSON 输出（工具调用必备）
  5. LangChain 基础：ChatModel、PromptTemplate、Parser、Document；理解 LCEL

✅ 小 Demo：简历文本结构化抽取；封装可复用大模型调用 SDK

阶段2｜RAG 检索增强（AI 应用核心，6周，JD 高频）

  1. 文档处理：PDF/Markdown、清洗、分块（固定/语义），理解分块对召回的影响
  2. Embedding；向量库：FAISS → Chroma → Milvus（企业优先熟悉 Milvus）
  3. 全链路：入库 → 向量化 → 检索 → Rerank → LLM 生成
  4. 调优：幻觉、召回差、噪声；简单效果评估
  5. FastAPI 封装 HTTP；并发、超时、参数校验

✅ 项目：私有知识库问答（标准 AI 应用简历项）

阶段3｜Function Calling + Agent 前置（3周）

  1. 工具调用原理；LangChain Tool、自定义工具
  2. 异常：参数错误、JSON 失败、超时、重试
  3. 多轮对话、会话状态、上下文裁剪；Redis 存会话

    LangChain 适合简单线性链路；复杂循环/分支用 LangGraph

✅ Demo：Agent 按需调用「简历打分 / 岗位查询」等工具，非手动点选

阶段4｜Agent 开发（6周，重点 LangGraph）

  1. 理论：ReAct；规划 / 工具 / 短记忆 / 长记忆；了解 MCP 概念
  2. LangChain 预构建 Agent 快速上手（简单任务）
  3. LangGraph 攻坚（企业更看重）
    • StateGraph、Node、Edge、条件分支、循环
    • Checkpointer、中断恢复、Human-in-the-loop
    • 短期状态 + 向量长期记忆
  4. 多工具编排；死循环、幻觉、失败兜底
  5. AutoGen/CrewAI 了解即可；吃透 LangGraph
  6. 简单评测：任务成功率、幻觉率脚本

✅ 完整项目：求职 Agent（比赛/简历）

上传简历 → 解析 → 岗位检索 → 匹配打分 → 缺陷诊断 → 优化建议；含重试与状态持久化

阶段5｜工程化打磨 & 面试（约 2 个月，贯穿后期）

  1. 限流、缓存、日志、降级、超时
  2. Docker 部署，云服务器上线
  3. 能口述难点与优化；能答：不用 LangGraph 如何手写简易状态机
  4. 题库：RAG、LangChain vs LangGraph、死循环、幻觉

至此可投：AI 应用、大模型应用开发、Agent 开发

阶段6｜进阶 Harness / Agent 基础设施（可选 8～12周，主线天花板）

在阶段4～5项目跑通后再学。目标：从「调框架写应用」进到「懂 Agent 怎么跑在系统上」。

  1. Agent Runtime / Loop：一步步「思考→调用工具→写回状态」的循环如何实现；与 LangGraph 执行模型对照
  2. 工具系统：工具注册、Schema、权限、超时与隔离；MCP 若有余力可深一点
  3. 沙箱：Docker（必会概念与实践）；了解 Wasm 等隔离思路（面试加分）
  4. 上下文与状态：窗口管理、摘要、Checkpointer/持久化、多会话
  5. 可观测性：Tracing（调用链）、日志、指标；一次请求里模型/工具耗时怎么查
  6. 评测与稳定性：回归集、成功率、失败重放；并发与限流

✅ 产出：在已有 Agent 上补一版「迷你 Harness」说明文档 + 关键模块（如统一工具网关、Tracing、会话持久化），简历表述升级为「参与/实现 Agent 运行时能力」

投递话术：主投应用/Agent；Harness 作同赛道加深，对口岗少但区分度高。

支线1：后训练 / 模型微调（了解 + 小实验，不主攻基座）

目标： 能看懂 SFT/LoRA JD，能独立跑通一次垂类微调小实验，和主线 Agent「会调模型、懂模型从哪来」形成互补；不对标基座预训练研究员。

目标岗位（了解/兼投）： 大模型微调（SFT）助理向、应用岗中带「会微调优先」的 JD；主简历仍以主线1为主。

周期： 穿插主线，约 6～10 周集中学 + 1 个小项目即可（可与主线阶段4后并行）。

招聘里常考/常写： 数据构造、SFT、LoRA/QLoRA、评测；RLHF/DPO 知概念即可。

阶段1｜概念与数据（2周）

  1. 预训练 vs 后训练 vs 推理；SFT / RLHF / DPO 各自解决什么问题
  2. 指令数据长什么样；怎么从业务日志/文档构造「问题-回答」对
  3. 过拟合、灾难遗忘、评测集（别只看 loss）

阶段2｜LoRA/QLoRA 实操（3～4周）

  1. 环境：单机单卡或云 GPU；HuggingFace Transformers + PEFT/trl 基本流程
  2. 选小模型或 API 厂开源小模型做 SFT/LoRA；学会看显存与 batch
  3. 推理对比：微调前 vs 微调后在垂类问题上的表现

✅ Demo：某一垂直小领域（如简历要点抽取、地学/电子简单问答）LoRA 微调 + 前后对比报告

阶段3｜和主线打通（1～2周）

  1. 微调后的模型如何接到主线 RAG/Agent（本地 vLLM/Ollama 或平台部署二选一即可）
  2. 简历一句话：主线 Agent +「具备 LoRA/SFT 小规模落地经验」

RLHF 全链路、多机分布式训练留给以后；支线1到 LoRA + 数据构造足够。

支线2：CUDA AI-GPU 性能优化（AI-Infra / GPU 算子向）

目标岗位：GPU 算子工程师、推理引擎工程师、AI 系统工程师、分布式训练工程师
周期：入门可写简历 Demo 需 8～12 个月；高质量项目 12～18 个月
招聘核心考察：C++、计算机体系结构、GPU 存储层级、CUDA Kernel、Profiler、计算/带宽瓶颈；了解 LLM 推理（KV-Cache、Attention）

阶段0｜底层前置基础（8周，重中之重，0基础必须啃完再碰 CUDA）

  1. C++ 进阶：C++11/17，指针内存、STL、模板、错误处理；能写中等规模 C++
  2. 计算机体系结构：缓存、带宽、算力、SIMD；计算 bound / 内存 bound
  3. 操作系统：内存、线程、同步、竞争
  4. 并行计算：并行思维、归约、同步原语

阶段1｜CUDA 基础编程（6周）

  1. 编程模型：Grid-Block-Thread，Kernel
  2. 存储层次：全局/共享/寄存器/常量；合并访问、warp、bank 冲突
  3. 拷贝、__syncthreads()、原子操作；错误检查
  4. Nsight Profiler，定位瓶颈

✅ Demo：向量加法、归约求和 Kernel，性能对比

阶段2｜深度学习核心算子 CUDA（8周，面试高频）

  1. GEMM：tiling、共享内存优化；对比 cuBLAS
  2. Softmax、LayerNorm
  3. Tensor-Core、FP16/BF16；精度与性能权衡

✅ Demo：优化版 GEMM，输出带宽/算力利用率

阶段3｜面向 LLM 推理加速（8周，简历核心项目）

  1. Transformer GPU 流程，KV-Cache（面试常问）
  2. PagedAttention、vLLM 原理/源码阅读
  3. 简化版 Attention / KV-Cache 算子 + 调优
  4. INT8/INT4 量化原理了解

✅ 项目：简化 KV-Cache/Attention 算子，对比时延与显存

阶段4｜进阶拓展（有余力，非硬性）

  1. 分布式与 NCCL 概念
  2. DeepSpeed/Megatron；昇腾 CANN 概念
  3. TensorRT 概念

阶段5｜面试准备

  1. 手撕：归约、GEMM 优化、合并访问、bank 冲突
  2. KV-Cache 显存估算，带宽/算力瓶颈分析
  3. C++ 与计算机底层复习

可投 AI-Infra、GPU 算子、推理性能等；该方向岗位更集中北上深，武汉可兼顾存储/芯片周边（如长江存储等）与远程岗。

三条线怎么排时间（建议）

顺序 做什么 备注
先 主线1 阶段1～5 保研/就业主故事
插空 支线1 主线 RAG/Agent 稳定后插入，6～10 周
长期 支线2 与主线并行啃 C++/体系结构；CUDA 项目作第二技能点
可选加深 主线1 阶段6 Harness 应用项目扎实后再上

简历主叙事示例：
「电子信息硕｜主做大模型应用与 Agent（RAG + LangGraph + 上线工程）；具备 LoRA/SFT 小规模微调经验；了解 CUDA/GPU 与推理加速基础。」
