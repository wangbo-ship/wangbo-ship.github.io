C++ / CUDA 系统化学习路线

目标岗位画像：CUDA 开发、GPU 并行计算、AI 算子优化、推理引擎底层、高性能计算（HPC）。
一句话：不做「调包训模型」，做 GPU 上把算子写快、写对、写稳。

岗位怎么理解（先定方向）

更接近你的方向 暂时不用深挖
CUDA Kernel / 访存与并行优化 完整深度学习算法推导、炼丹调参
GEMM、Reduce、Softmax、Norm、Attention 等 底层算子 Web、业务后端、纯 Python 应用开发
Roofline、带宽瓶颈 vs 算力瓶颈、Nsight 调优 大模型应用、RAG、Agent 产品
库：cuBLAS / cuDNN 会用 + 知道何时该手写 从零搭训练平台、分布式策略全集
了解昇腾 CANN（国内算力迁移加分） 一上来死磕全部国产工具链细节

常见招聘关键词可对照：CUDA、算子开发/优化、GPU、高性能计算、推理加速、并行计算、异构计算。

一、整体说明

项目 说明
总周期 4–6 个月（每天 2–3 小时；零基础可 6–8 个月）
核心原则 C/C++ 过门槛就上 CUDA，在 Kernel 实战里反补语法短板
学成定位 手写并优化 CUDA Kernel；能用性能模型解释快慢；能对接 AI 框架做自定义算子；了解国产算力迁移思路

前提自检： 有一门编程基础会更快；已有 C/C++ 可将阶段 1–2 压到 1–2 周。

二、阶段 0：环境准备（第 1 周）

1. 必备环境

  • 编译器：GCC / MSVC（VS2022）
  • 硬件：NVIDIA 显卡（建议算力 ≥ 7.5）；无本地卡可用 AutoDL / 云 GPU
  • 软件：驱动、CUDA Toolkit、CMake、Nsight Systems、Nsight Compute

2. 学习目标

能编译运行 C++ / CUDA；熟悉命令行与 CMake。

3. 达标要求

跑通 CUDA Hello World；能打开一份 Nsight 报告（先会用工具）。

三、阶段 1：C 语言筑基（第 2–3 周）

Kernel 是 C 风格并行代码，指针 + 内存布局是硬门槛。

1. 必学

  1. 基础语法：类型、运算符、分支循环、函数
  2. 数组：一维 / 二维排布、连续性
  3. 指针：运算、多级指针、与数组的关系
  4. 堆内存：malloc / calloc / realloc / free，泄漏与越界
  5. 结构体：对齐、成员偏移
  6. 预处理：头文件保护、#define

2. 选学

位运算、简单文件 IO

3. 强制练习

  1. 堆上 float 数组 + 指针遍历修改
  2. 一维模拟二维，吃透线性寻址（对应显存索引）
  3. 打印结构体成员偏移，理解对齐

4. 达标标准

能徒手写指针遍历；能讲清对齐；无明显内存错误。

四、阶段 2：C++ 核心（第 4–6 周，Host 端）

1. 必学

  1. namespace、引用、三种传递方式
  2. OOP 极简：类、访问权限、构造 / 析构（继承多态 暂缓，读框架时再补）
  3. 模板：函数模板、类模板（读 cuBLAS 封装 / 泛型算子代码用）
  4. RAII、unique_ptr / shared_ptr（Host）
  5. STL：vector / array / string、sort；map 等了解即可
  6. CMake 多文件工程

2. 延后

lambda、右值引用、std::move、std::thread

3. 先不碰

设计模式、网络、GUI、协程、Boost、模板元编程

4. 强制练习

  1. vector<float> 模拟 Host 侧数据准备
  2. 模板：求和 / 求 max
  3. CMake 编译多文件工程

5. 达标标准

会管 Host 内存、能读模板、能 CMake 编译 → 进 CUDA。

五、阶段 3：CUDA 入门 + 并行思维（第 7–9 周）

1. 核心知识

  1. Host / Device，主机内存 vs 显存
  2. __global__ / __host__ / __device__
  3. Grid–Block–Thread，一维索引
  4. cudaMalloc / cudaMemcpy / cudaFree + 错误检查宏
  5. Thrust 仅作辅助（不能替代手写 Kernel）

2. 并行计算入门概念（尽早建立）

  • 什么是数据并行；为什么 GPU 适合高吞吐
  • 粗懂：算力瓶颈 vs 带宽瓶颈（后面用 Roofline 深化）

3. 实战

  1. 向量加法
  2. 点积
  3. Thrust 排序（对比手写）

4. 达标标准

独立跑通：准备数据 → 拷显存 → Kernel → 回拷 → 结果校验。

六、阶段 4：CUDA 中级调优（第 10–14 周，求职核心）

AI 底层 / HPC 面试最看重：Kernel 正确性 + 优化证据 + 能讲清瓶颈。

1. 高频硬知识点

  1. 二维网格与矩阵索引
  2. 内存层级：全局 / 共享 / 寄存器 / 常量 / 局部
  3. 合并访问（coalescing）
  4. Shared Memory Tiling
  5. Warp、分支发散、Bank Conflict
  6. Stream：异步拷贝与计算重叠
  7. Occupancy 基础
  8. 原子操作场景与坑
  9. 工具：Nsight Compute（单 Kernel）+ Nsight Systems（整条流水线）
  10. Roofline 思维：先判断受限于算力还是带宽，再选优化手段

2. 必做调优项目

  1. 朴素 MatMul → Shared Memory 分块；与 cuBLAS 对比数量级
  2. 并行 Reduce
  3. 卷积 / im2col 思路（理解 CNN 算子为何吃带宽）

3. 库能力（底层岗标配）

  • 会调 cuBLAS 做 GEMM；知道手写 Kernel 与调库各自场景
  • 了解 cuDNN 存在即可（卷积 / Norm 等常被库吃掉）

4. 达标标准

能交付优化版 MatMul + Nsight 结论；能口述「慢在访存还是计算」。

七、阶段 5：AI 底层算子 + 国产算力（第 15–20 周）

这一阶段把「会 CUDA」接到 AI 算力栈：训练/推理框架底下的那一层。

1. 优先掌握的算子族（按含金量）

优先级 算子 / 主题 为何重要
高 GEMM / 分块 MatMul、Reduce 一切性能的底座
高 Softmax、LayerNorm / RMSNorm、Elementwise、激活 推理与 Transformer 高频
高 混合精度、Tensor Core 概念与使用边界 AI 算力岗几乎必问
中 算子融合（如 bias+relu、融合 Norm） 减少访存往返
中 Attention 相关（先理解计算图与瓶颈，再考虑手写） 大模型推理方向加分
低 动态并行等冷门特性 了解即可

2. 接到框架：PyTorch CUDA Extension（强烈建议）

不是为了学 Python 业务，而是证明你能把 Kernel 接到 AI 栈：

  • torch.utils.cpp_extension 写自定义算子（RMSNorm 或 fused bias+relu）
  • Python 调用 + 与 PyTorch 原生实现做正确性 / 速度对比

3. 国产算力（国内岗位容错）

  1. 昇腾 CANN / Ascend C 模型有个整体印象
  2. CUDA SIMT vs 达芬奇数据流：能对比说清
  3. 目标：读懂 CUDA 算子后，能讲「迁移时要改什么」，不必先背全 API

4. 简历主项目（GitHub）

做一个 小型 GPU 算子库，突出「并行计算 + 算子优化」：

  • 至少：Reduce、优化 MatMul、1 个 Norm/Softmax、1 个融合算子
  • 每个算子固定四段：朴素 → 优化 → Nsight/数据 → vs cuBLAS 或 PyTorch
  • README 写清：环境、编译、瓶颈判断、优化点、加速比

可选加分：多流流水线；或读一点 CUTLASS / 开源 Norm 实现（读结构，不求重写）。

八、时间投入模板

阶段 每周 C++ 每周 CUDA / 并行
阶段 0–2 12–15h 0h
阶段 3 2–3h 10–12h
阶段 4–5 ≤2h 12–15h

九、避坑准则

  1. 别在应用层绕太久：目标是算子与性能，不是业务模型调参
  2. 别只看书不动手：每次优化都要有数字和 Nsight 依据
  3. 别只会手写不会用库：cuBLAS 等是基线；手写是为了不可替代的算子与理解
  4. 别只会 CUDA 语法：要能用 Roofline / 带宽 / Occupancy 解释「为什么快」
  5. 国内岗：CUDA 做深，昇腾作了解，扩大匹配面

十、学成能力清单

  1. C/C++ 满足 GPU Host/Device 开发，指针与内存无硬伤
  2. 独立实现并优化 CUDA Kernel，能定位算力/带宽瓶颈
  3. 熟悉 AI 高频底层算子，能做融合与混合精度层面的优化讨论
  4. 能通过 Extension 把算子接到 PyTorch，完成正确性与性能对比
  5. 了解 CUDA → 昇腾迁移逻辑；有可展示的算子库与调优报告

十一、面试前 2–3 周

  • 口述：合并访问、Shared Memory、Warp、Stream、Occupancy、Roofline
  • 白板：向量加、Reduce、分块 MatMul 索引
  • 项目答辩：每个优化点对应哪张图、相对基线快多少
  • 选读：CUTLASS 或开源 RMSNorm/Softmax Kernel（懂分层与模板思路即可）
  • 岗位话术：强调「并行计算 + CUDA 算子优化 + AI 底层算力」，避免被理解成算法研究员或应用开发
